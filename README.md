# Football Player Performance Analysis

## Overview

This project investigated the relationship between player wages and performance in the English Premier League during the 2023/24 season.

Data were collected from Capology and FotMob, focusing on the 50 highest-performing and 50 lowest-performing players.

## Methods

The analysis used Python to explore the relationship between player wages and performance through:

- Descriptive statistics and data visualisation.
- Linear regression.
- Permutation analysis using 1,000 simulations.

Key libraries included SciPy and Statsmodels.

## Findings

The analysis identified a positive and statistically significant relationship between wages and performance. However, wages were not a significant predictor of performance among lower-performing players.

## Limitations

The dataset was limited to 100 players rather than the entire Premier League. Future analysis could incorporate additional variables, such as playing time, to provide a more comprehensive understanding of player performance.
